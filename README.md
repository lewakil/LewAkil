## 🚙 Public Project

### [Golf Cart Tracker](https://github.com/lewakil/GolfCart)

A full-stack React + Node application for monitoring a golf-cart fleet with live-style telemetry, GPS position, trips, geofences, battery state, alerts, reservations, and maintenance workflows.

`React` `Node.js` `APIs` `Telemetry` `Maps` `Integrations`

The project includes a deterministic demo data provider plus an optional Trackunit-backed integration, so it can be explored without private fleet credentials.
